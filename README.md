# Postman API Automation

## Project Overview
API automation testing using Postman on a public REST API (ReqRes).

## Tools & Technologies
- Postman
- JavaScript (Postman Tests)
- REST APIs

## APIs Covered
- GET: List Users
- GET: Single User
- POST: Create User
- PUT: Update User
- DELETE: Delete User

## Test Validations
- Status code validation
- Response time validation
- Response body validation
- Dynamic variable handling
- Environment variables

## How to Run
1. Import collection from `/collections`
2. Import environment from `/environments`
3. Select environment in Postman
4. Run using Collection Runner
